# Hi, I’m Atefe Nayamadi Mahmoodabadi

**Postdoctoral Researcher at Uppsala University · Computational Physics · Machine Learning for Materials**

I am a researcher with a background in condensed matter physics and machine learning for materials. My PhD at Ferdowsi University of Mashhad focused on predicting the magnetic properties of two-dimensional ferromagnetic materials using machine learning.

## Research interests

- Two-dimensional magnetic materials
- Atomic fingerprints and materials descriptors
- Computational condensed matter physics

## Research code

[**Fingerprint**](https://github.com/Atefenm/Fingerprint-) — Exploratory Python code for constructing atomic fingerprints from structural and elemental information, with a neural-network modelling component.
